# User Story – Registrera Shelters

Som klanledare  
vill jag kunna registrera Shelters med namn och koordinater  
för att systemet ska kunna beräkna korrekt förbrukning.

## Acceptanskriterier
- En Shelter kan registreras med namn och koordinater  
- När en ny Shelter registreras ökar antalet Shelters med 1
